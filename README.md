# Python Data Science Foundations

This repository contains my first steps learning Python for data science, 
following the IBM Python for Data Science, AI & Development course on Coursera.

I'm a Clinical Laboratory Technician transitioning into Behavioural Data Science, 
and these notebooks document my learning process from the ground up.

## Notebooks

### Module 1 — Python Basics
`module_1_python_basics.ipynb`

Covers the fundamental building blocks of Python: data types (int, float, 
string, boolean), type conversion, expressions and operators, variable 
assignment, and string manipulation. Examples are applied to health and 
behavioural data contexts.

### Module 2 — Python Data Structures
`Module_2_Python_Structure.ipynb`

Covers core Python data structures: tuples, lists, dictionaries and sets. 
Includes practical examples using patient data and clinical symptom sets.
